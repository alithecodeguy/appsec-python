## 1. Scoped database queries, ownership checks and minimal response fields

### Carry chapter 41's field contract into code

`request_export` accepts an object containing only `note_ids` and the separate retry key. The normalized selection is 1–10 distinct positive integer IDs. A Boolean is not an accepted ID. The authenticated user is supplied outside that object.

The application checks active membership and every selected note through chapter 23's `selected_rows`. An Alpha request containing Beta note `202` fails entirely. The original requester, workspace, selection and timestamps are stored as durable intent. No field named `requested_by`, `state`, `expires_at` or `object_key` is accepted from the client.

A **reservation** counts capacity for one possible retained payload. Admission counts queued requests and outstanding reservations inside the same write transaction as insertion. Limits remain one queued request per workspace, two globally, two retained reservations per workspace and four globally. Ready or expired ciphertext continues to consume its reservation until verified deletion.

**Table T42-02. Three kinds of identity**

| Value | Trusted source | Use |
| --- | --- | --- |
| Human `user_id` | Validated session; fixture caller in local tests | Current member, requester and manager decisions |
| Worker's `workspace_id` | Restricted worker configuration | Partition of durable jobs and configured export keys |
| Message `job_id` | Bounded decoded work reference | Candidate lookup only; cannot override stored requester/workspace |

`authorized_job` requires current membership, binds route workspace to the stored job and checks requester equality. Only the early-expiry operation may additionally use current manager authority in that same workspace. Lee may expire Mina's Alpha artifact but cannot collect it; he has no Beta management bypass.

### The complete local service

**Listing L42-01. Admission, worker publication, release and lifecycle units**

Filename: `examples/ch42/capstone.py`.

```python
"""CB-EXPORT-41 revision 1: isolated local service, no caller-supplied identity authority."""
from dataclasses import dataclass
import json
import re
import sqlite3

from examples.ch23.authorization_service import (
    AccessDenied, export_selection, positive_id, require_member, selected_rows, unit,
)
from examples.ch27.export_crypto import (
    MAX_PLAINTEXT, CannotOpen, authorize_record, decrypt, encrypt, initialize as initialize_crypto,
)

POLICY = "CB-EXPORT-41-r1"
LIFETIME, GRACE, RETENTION = 60, 900, 7*86400
TERMINAL = {"denied", "failed", "expired"}


class Problem(ValueError):
    def __init__(self, status, code):
        self.status, self.code = status, code
        super().__init__(code)


class Cancelled(Exception):
    pass


@dataclass
class Clock:
    value: int = 1795687200  # 2026-11-26 10:00:00 UTC, exercise time only.
    def __call__(self):
        return self.value


def initialize(database):
    initialize_crypto(database)  # Fresh path only; preserves chapter 23's seed.
    with unit(database, write=True) as db:
        db.execute("""CREATE TABLE jobs (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            requested_by INTEGER NOT NULL REFERENCES users(id),
            workspace_id INTEGER NOT NULL REFERENCES workspaces(id),
            client_key TEXT NOT NULL, note_ids TEXT NOT NULL,
            created_at INTEGER NOT NULL, expires_at INTEGER NOT NULL, closed_at INTEGER,
            state TEXT NOT NULL CHECK(state IN ('queued','ready','denied','failed','expired')),
            reserved INTEGER NOT NULL CHECK(reserved IN (0,1)),
            deleted_at INTEGER, retain_until INTEGER, cleanup_error TEXT,
            breached INTEGER NOT NULL DEFAULT 0 CHECK(breached IN (0,1)),
            UNIQUE(requested_by,workspace_id,client_key))""")
        db.execute("""CREATE TABLE result_slots (
            job_id INTEGER NOT NULL PRIMARY KEY REFERENCES jobs(id),
            export_id INTEGER UNIQUE REFERENCES encrypted_exports(id))""")
        db.execute("""CREATE TABLE export_events (
            id INTEGER PRIMARY KEY AUTOINCREMENT, job_id INTEGER NOT NULL REFERENCES jobs(id),
            workspace_id INTEGER NOT NULL, actor TEXT NOT NULL, outcome TEXT NOT NULL,
            at INTEGER NOT NULL, policy TEXT NOT NULL)""")


def event(db, job, actor, outcome, at):
    db.execute("INSERT INTO export_events (job_id,workspace_id,actor,outcome,at,policy) VALUES (?,?,?,?,?,?)",
               (job["id"], job["workspace_id"], actor, outcome, at, POLICY))


def access_end(job):
    return min(job["expires_at"], job["closed_at"] if job["closed_at"] is not None else job["expires_at"])


def effective_state(job, now):
    return "expired" if job["state"] not in TERMINAL and now >= access_end(job) else job["state"]


def authorized_job(db, user_id, workspace_id, job_id, *, manager=False):
    role = require_member(db, user_id, workspace_id)
    if not positive_id(job_id):
        raise AccessDenied()
    row = db.execute("SELECT * FROM jobs WHERE id=? AND workspace_id=?", (job_id, workspace_id)).fetchone()
    if row is None or (row["requested_by"] != user_id and not (manager and role == "manager")):
        raise AccessDenied()
    return dict(row)


def request_export(database, *, user_id, workspace_id, body, client_key, clock):
    with unit(database, write=True) as db:
        require_member(db, user_id, workspace_id)
        if (not isinstance(body, dict) or set(body) != {"note_ids"}
                or not isinstance(body["note_ids"], list) or not isinstance(client_key, str)
                or re.fullmatch(r"[A-Za-z0-9_-]{1,40}", client_key) is None):
            raise Problem(400, "invalid_request")
        try:
            ids = export_selection(body["note_ids"])
        except ValueError as exc:
            raise Problem(400, "invalid_request") from exc
        selected_rows(db, user_id=user_id, workspace_id=workspace_id, note_ids=ids)
        encoded = json.dumps(ids)
        prior = db.execute("""SELECT * FROM jobs WHERE requested_by=? AND workspace_id=? AND client_key=?""",
                           (user_id, workspace_id, client_key)).fetchone()
        if prior is not None:
            if prior["note_ids"] != encoded:
                raise Problem(409, "request_conflict")
            return {"job_id":prior["id"], "workspace_id":workspace_id, "state":"queued"}
        counts = db.execute("""SELECT count(*),coalesce(sum(workspace_id=?),0) FROM jobs
            WHERE state='queued'""", (workspace_id,)).fetchone()
        held = db.execute("""SELECT count(*),coalesce(sum(workspace_id=?),0) FROM jobs
            WHERE reserved=1""", (workspace_id,)).fetchone()
        if counts[0] >= 2 or counts[1] >= 1 or held[0] >= 4 or held[1] >= 2:
            raise Problem(429, "capacity_exhausted")
        now = clock()  # Service clock sampled after acquiring the transaction, never request JSON.
        job_id = db.execute("""INSERT INTO jobs
            (requested_by,workspace_id,client_key,note_ids,created_at,expires_at,state,reserved)
            VALUES (?,?,?,?,?,?,'queued',1)""",
            (user_id,workspace_id,client_key,encoded,now,now+LIFETIME)).lastrowid
        job = dict(db.execute("SELECT * FROM jobs WHERE id=?", (job_id,)).fetchone())
        event(db, job, f"user:{user_id}", "accepted", now)
        return {"job_id":job_id, "workspace_id":workspace_id, "state":"queued"}


def status(database, *, user_id, workspace_id, job_id, clock):
    with unit(database) as db:
        job = authorized_job(db, user_id, workspace_id, job_id)
        return {"job_id":job_id, "workspace_id":workspace_id,
                "state":effective_state(job,clock()), "expires_at":job["expires_at"]}


def close_job(db, job, state, now, actor):
    if job["state"] in TERMINAL:
        return job["state"]
    end = min(now, access_end(job))
    artifact = db.execute("SELECT export_id FROM result_slots WHERE job_id=?", (job["id"],)).fetchone()
    exists = artifact is not None and artifact["export_id"] is not None
    if not exists:
        db.execute("DELETE FROM result_slots WHERE job_id=?", (job["id"],))
    db.execute("""UPDATE jobs SET state=?,closed_at=?,reserved=?,retain_until=? WHERE id=?""",
               (state,end,int(exists),None if exists else end+RETENTION,job["id"]))
    event(db, job, actor, state, now)
    return state


def decode_message(raw):
    if not isinstance(raw, bytes) or len(raw) > 128:
        raise Problem(400, "invalid_message")
    def pairs(items):
        result = {}
        for key,value in items:
            if key in result: raise ValueError("duplicate key")
            result[key] = value
        return result
    try:
        message = json.loads(raw.decode("utf-8"), object_pairs_hook=pairs)
    except (ValueError, UnicodeDecodeError, RecursionError) as exc:
        raise Problem(400, "invalid_message") from exc
    if not isinstance(message,dict) or set(message) != {"job_id"} or not positive_id(message["job_id"]):
        raise Problem(400, "invalid_message")
    return message["job_id"]


def work(database, *, workspace_id, job_id, keyrings, clock, after_probe=None, checkpoint=None, stop=None):
    # workspace_id and keyrings come from trusted worker configuration, not its message.
    if not positive_id(workspace_id) or not positive_id(job_id) or workspace_id not in keyrings:
        raise Problem(404, "not_found")
    with unit(database) as db:
        missing = db.execute("SELECT 1 FROM result_slots WHERE job_id=?", (job_id,)).fetchone() is None
    if after_probe is not None: after_probe(missing)  # Test hook outside the write transaction.
    with unit(database, write=True) as db:
        row = db.execute("SELECT * FROM jobs WHERE id=? AND workspace_id=?", (job_id,workspace_id)).fetchone()
        if row is None: raise Problem(404, "not_found")
        job, now = dict(row), clock()
        if job["state"] in TERMINAL: return job["state"]
        if now >= access_end(job): return close_job(db,job,"expired",now,"worker")
        db.execute("SAVEPOINT preparation")
        won = db.execute("""INSERT INTO result_slots (job_id) VALUES (?)
            ON CONFLICT(job_id) DO NOTHING RETURNING job_id""", (job_id,)).fetchone()
        if won is None:
            db.execute("RELEASE preparation")
            return "duplicate"
        def refuse(state):
            db.execute("ROLLBACK TO preparation")
            db.execute("RELEASE preparation")
            return close_job(db,job,state,clock(),"worker")
        try:
            rows = selected_rows(db, user_id=job["requested_by"], workspace_id=job["workspace_id"],
                                 note_ids=json.loads(job["note_ids"]))
        except AccessDenied:
            return refuse("denied")
        payload = json.dumps({"workspace_id":workspace_id,"notes":rows},
                             ensure_ascii=False,separators=(",",":")).encode("utf-8")
        if len(payload) > MAX_PLAINTEXT: return refuse("failed")
        keyring = keyrings[workspace_id]
        export_id = db.execute("""INSERT INTO encrypted_exports
            (workspace_id,requested_by,note_ids,format_version,generation,key_id,nonce,ciphertext)
            VALUES (?,?,?,1,1,?,X'',X'')""",
            (workspace_id,job["requested_by"],job["note_ids"],keyring.active)).lastrowid
        record = dict(db.execute("SELECT * FROM encrypted_exports WHERE id=?", (export_id,)).fetchone())
        kid,nonce,ciphertext = encrypt(db,record,payload,keyring)
        db.execute("UPDATE encrypted_exports SET key_id=?,nonce=?,ciphertext=? WHERE id=?",
                   (kid,nonce,ciphertext,export_id))
        if checkpoint is not None: checkpoint()  # Test-controlled stop/time change; no external I/O in production.
        if stop is not None and stop.is_set(): raise Cancelled("preparation_cancelled")
        if clock() >= access_end(job): return refuse("expired")
        db.execute("UPDATE result_slots SET export_id=? WHERE job_id=?", (export_id,job_id))
        db.execute("RELEASE preparation")
        changed = db.execute("UPDATE jobs SET state='ready' WHERE id=? AND state='queued'", (job_id,)).rowcount
        if changed != 1: raise RuntimeError("publication_conflict")
        event(db,job,"worker","ready",clock())
        return "created"


def collect(database, *, user_id, workspace_id, job_id, keyrings, clock):
    # Write unit also makes the required local decision event part of successful release authorization.
    with unit(database, write=True) as db:
        job = authorized_job(db,user_id,workspace_id,job_id)
        selected_rows(db,user_id=user_id,workspace_id=workspace_id,note_ids=json.loads(job["note_ids"]))
        state = effective_state(job,clock())
        if state in TERMINAL or job["deleted_at"] is not None: raise Problem(410,"export_unavailable")
        if state != "ready": raise Problem(409,"export_not_ready")
        row = db.execute("""SELECT e.* FROM encrypted_exports AS e
            JOIN result_slots AS s ON s.export_id=e.id WHERE s.job_id=?""", (job_id,)).fetchone()
        if row is None or workspace_id not in keyrings: raise CannotOpen("export_unavailable")
        record = dict(row)
        if (record["workspace_id"] != workspace_id or record["requested_by"] != user_id
                or record["note_ids"] != job["note_ids"]):
            raise CannotOpen("export_unavailable")
        authorize_record(db,record,user_id)
        plaintext = decrypt(record,keyrings[workspace_id])
        now = clock()
        if now >= access_end(job): raise Problem(410,"export_unavailable")
        event(db,job,f"user:{user_id}","collect_authorized",now)
        return plaintext  # Context manager commits the event before the caller gets these bytes.


def expire(database, *, user_id, workspace_id, job_id, clock):
    with unit(database, write=True) as db:
        job = authorized_job(db,user_id,workspace_id,job_id,manager=True)
        return close_job(db,job,"expired",clock(),f"user:{user_id}")


def cleanup(database, *, job_id, clock):
    # Privileged maintenance. No keyring/decrypt operation and no caller-provided storage locator.
    try:
        with unit(database, write=True) as db:
            row = db.execute("SELECT * FROM jobs WHERE id=?", (job_id,)).fetchone()
            if row is None: return "missing"
            job, now = dict(row), clock()
            if job["state"] not in TERMINAL:
                if now < access_end(job): return "not_due"
                close_job(db,job,"expired",now,"cleanup")
                job = dict(db.execute("SELECT * FROM jobs WHERE id=?", (job_id,)).fetchone())
            if job["deleted_at"] is not None: return "deleted"
            slot = db.execute("SELECT export_id FROM result_slots WHERE job_id=?", (job_id,)).fetchone()
            if slot is None: return "no_payload"
            db.execute("DELETE FROM result_slots WHERE job_id=?", (job_id,))
            db.execute("DELETE FROM encrypted_exports WHERE id=?", (slot["export_id"],))
            db.execute("""UPDATE jobs SET reserved=0,deleted_at=?,retain_until=?,cleanup_error=NULL,
                breached=max(breached,?) WHERE id=?""",
                (now,now+RETENTION,int(now > access_end(job)+GRACE),job_id))
            event(db,job,"cleanup","deleted",now)
            return "deleted"
    except sqlite3.Error:
        # The local deletion/receipt unit rolled back. Record retry-required, if storage is usable.
        with unit(database, write=True) as db:
            row = db.execute("SELECT * FROM jobs WHERE id=?", (job_id,)).fetchone()
            if row is None: raise
            job, now = dict(row), clock()
            if job["state"] not in TERMINAL and now >= access_end(job):
                close_job(db,job,"expired",now,"cleanup")
                job = dict(db.execute("SELECT * FROM jobs WHERE id=?", (job_id,)).fetchone())
            db.execute("UPDATE jobs SET cleanup_error='retry_required',breached=max(breached,?) WHERE id=?",
                       (int(now > access_end(job)+GRACE),job_id))
            event(db,job,"cleanup","delete_failed",now)
        return "retry"


def purge(database, *, job_id, clock):
    with unit(database, write=True) as db:
        job = db.execute("SELECT * FROM jobs WHERE id=?", (job_id,)).fetchone()
        if job is None: return False
        if job["reserved"] or job["retain_until"] is None or clock() < job["retain_until"]: return False
        db.execute("DELETE FROM export_events WHERE job_id=?", (job_id,))
        db.execute("DELETE FROM result_slots WHERE job_id=?", (job_id,))
        db.execute("DELETE FROM jobs WHERE id=?", (job_id,))
        return True  # AUTOINCREMENT preserves the job-ID high-water mark; nonce history remains.


def snapshot(database):
    # Full privileged test evidence; never publish, serve, or log these rows.
    with unit(database) as db:
        names = ("jobs","result_slots","encrypted_exports","used_nonces","export_events")
        return {name:[dict(row) for row in db.execute(f"SELECT * FROM {name} ORDER BY 1")]
                for name in names}
```

This file contains all domain operations so the transaction boundaries are visible together. Read `request_export`, `authorized_job` and `status` first for increment 1; continue to `work`/`collect` for increment 2 and `expire`/`cleanup`/`purge` for increment 3.

`jobs` stores intent, immutable creation/expiry, first closure, reservation state and minimal cleanup evidence. `result_slots.job_id` is a primary key: at most one result slot belongs to a job. Its `export_id` is unique. The temporarily empty slot exists only inside a worker's uncommitted preparation transaction; successful publication fills it, refusal removes it, and an unexpected exception rolls it back.

`export_events` stores only job/workspace references, a controlled actor label, outcome, service-clock time and policy version. It contains no note text, session secret or reusable storage locator. The `snapshot` helper is privileged test evidence: it returns actual ciphertext/nonce rows and must never become an HTTP endpoint or routine log output.

A successful initial request returns only `job_id`, `workspace_id` and the acceptance state `queued`. A retry returns the same receipt, even after processing; it is not a new status query. `status` returns only four fields, including effective state and original expiry. Times in this local model are integer UTC epoch seconds. No response contains a key ID, nonce or ciphertext location.

## 2. Worker authorization and storage key isolation

### Resolve intent again at the worker

`decode_message` accepts at most 128 raw bytes and exactly one positive `job_id`, rejecting duplicate JSON keys and extra authority fields. It does not establish who sent the message. An actual delivery adapter must authenticate its source; this local lab delivers references explicitly.

The configured workspace narrows `work`'s job lookup. A Beta-configured worker cannot process an Alpha job merely because the ID exists. It then reads requester and selected IDs from the durable record, checks current account/membership and loads every note through the established scope.

The worker exports the current visible contents at its database snapshot. It uses the exact allowed fields `id`, `workspace_id`, `title`, `body`, plus the document's workspace ID. It never exports membership data, key metadata or attachments. A compact UTF-8 serialization exceeding 4,096 bytes creates a terminal failed job with no published result. Selected rows and JSON are already materialized before this check, so it is not a whole-operation memory bound for arbitrarily large stored notes.

### Keep purpose and workspace keys separate

**Listing L42-02. Independent disposable fixture keyrings**

Filename: `examples/ch42/fixtures.py`.

```python
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
from examples.ch27.export_crypto import Keyring


def dummy_keyrings():
    # Disposable, independent keys; never persisted, printed, or used outside synthetic runs.
    return {workspace:Keyring({f"export-w{workspace}-demo":AESGCM.generate_key(bit_length=256)},
                             f"export-w{workspace}-demo") for workspace in (1,2)}
```

The mapping is trusted configuration. Each workspace gets fresh independent AES key material and a distinct configured key ID. The selected keyring is passed to chapter 27's maintained AES-GCM wrapper. No message selects a path, key URL or arbitrary secret.

Associated data still binds the encrypted record's ID, requester, workspace, selection representation, format, generation, key ID and fixed purpose. Collection also compares the record's intent fields with the job before opening it. Wrong keyrings and modified ciphertext fail without a returned plaintext value or a successful release event.

This is local key selection, not cloud IAM or protected KMS custody. Python objects containing key bytes do not isolate hostile code in the same process. Chapter 27's nonce, key-lifetime, rollback and backup cautions remain applicable. The SQL deletion routine deliberately needs no keyring or decryption operation.

### Coordinate the dangerous schedule

**Listing L42-03. Two deliveries of the same durable request**

Filename: `examples/ch42/workers.py`.

```python
from concurrent.futures import ThreadPoolExecutor
from threading import Barrier

from examples.ch28.export_queue import run_with_retry
from examples.ch42.capstone import work


def two_workers(database, *, workspace_id, job_id, keyrings, clock):
    gate = Barrier(2,timeout=5)
    def worker():
        observations = []
        def arrive(missing):
            observations.append(missing)
            gate.wait()
        result = run_with_retry(lambda:work(database,workspace_id=workspace_id,job_id=job_id,
            keyrings=keyrings,clock=clock,after_probe=arrive if not observations else None))
        return observations[0],result
    with ThreadPoolExecutor(max_workers=2) as pool:
        futures = [pool.submit(worker) for _ in range(2)]
        return [future.result(timeout=10) for future in futures]
```

The diagnostic read closes before the barrier. Both workers therefore observe no result before either writes. The observation is not a claim: inside the transaction, each attempts the targeted primary-key insert. One returns `created`; the other receives the committed conflict and returns `duplicate`.

Python supplies two scheduled calls, a barrier and result collection. The database supplies uniqueness and the local commit/rollback boundary. The first worker's slot, encrypted row, nonce reservation, ready update and required event commit together. A second connection cannot observe a deliberately committed half-publication in this protocol.

The retry helper from chapter 28 repeats only SQLite busy errors, with at most three attempts per delivery. It closes/restarts the failed unit and never re-enters a barrier whose peer has left. On exhaustion it propagates the error; there is no automatic infinite requeue. Durable scheduling budgets and a broker remain outside this lab. A timed-out future does not kill a running thread.

### Worked example 2: revoke between queueing and collection

Increment 2 creates an Alpha job for Mina and a Beta job for Ravi. Two workers receive Mina's ID; one worker receives Ravi's. Both intended requesters collect their own result. Lee then revokes Mina from Alpha, and Mina starts a new collection.

Predict what changes: the membership row becomes inactive. The stored export remains ready and encrypted. The new collection is refused before any bytes are returned, and its failed path adds no successful collection event. Ravi's Beta artifact is unaffected.

There is also a queue-delay variant in the tests. Revoke Mina before the worker's source check: processing returns denied, no result/ciphertext/nonce commits, and the unused payload reservation is released. Restoring membership later does not resurrect that terminal request.

**Table T42-04. Two revocation positions, different stored results**

| Revocation position | Worker result | Stored export | Next collection |
| --- | --- | --- | --- |
| Before worker source authorization | denied | No artifact; reservation released; terminal evidence retained | Refused |
| After ready publication | Previously created | Same ready artifact/reservation until expiry/cleanup | Refused by current membership |
| No revocation, active Ravi/Beta | created for Beta | Separate Beta key/record and exact selected fields | Ravi allowed; Alpha users denied |

`collect` performs a short write transaction because the required local `collect_authorized` event must commit before the caller receives plaintext. It checks current requester/workspace and complete note visibility, then ready/expiry state, verifies/decrypts, samples the clock again and writes the event. An event-write failure rolls back and returns no value to the caller.

The event says a collection was authorized, not that the browser received every byte. A new read after a committed revocation is denied. A copy already returned cannot be recalled. No server content cache or direct object grant is implemented; adding either requires tests that preserve this ordering rather than treating an old authorized result as reusable permission.

## 3. Idempotency, expiry, cancellation and failure cleanup

### Preserve the original clocks

The controlled `Clock` starts at `2026-11-26T10:00:00Z`. Admission samples it after obtaining the write transaction and stores a 60-second original expiry. Neither request replay nor queue redelivery refreshes it.

`access_end` is the earlier of original expiry and first terminal closure. `effective_state` treats a ready or queued record as expired at that time even if maintenance has not updated its stored state. The content gate independently compares trusted time. It does not wait for successful deletion or a timer tick.

`expire` reuses the human matrix: an active requester may end their own job, and an active scoped manager may end another job there. Closing a job without a payload frees its reservation and begins terminal metadata retention. Closing a ready job retains its reservation until deletion. A repeated close leaves the first closure and evidence unchanged.

### Use a savepoint for preparation that becomes too late

A **savepoint** marks a point within a transaction to which some changes can be rolled back. `work` uses `SAVEPOINT preparation` for its tentative slot, encrypted row and nonce reservation. If the clock reaches expiry after encryption, `ROLLBACK TO preparation` removes those tentative changes. The same outer transaction can then commit a truthful terminal expired outcome.

This avoids a false choice between committing a late artifact and rolling back the record of why publication was refused. Unexpected failures still roll back the entire outer unit. No candidate ciphertext is released externally before this decision.

The test `checkpoint` is trusted instrumentation after encryption, not an extension point for production HTTP or storage calls. A stop event at that point raises `Cancelled`. The outer context rolls back preparation and leaves the durable request queued with its original reservation/deadline. The supervisor owns any later bounded retry or expiry decision; cancellation is not a successful acknowledgement.

There are no plaintext temporary files in this core path. The suite separately reruns chapter 28's genuine asyncio cancellation fixture and verifies its temporary directory is empty. That check does not prove arbitrary executor threads stop when their wrappers are cancelled. Hard process termination, memory zeroization and abandoned external files need different evidence.

### Serialize early expiry with publication

The local `BEGIN IMMEDIATE` transaction orders a worker's publication and a human early-expiry operation. Tests force both relevant orders:

- **Expiry first:** the worker waits outside its write transaction. Lee expires the queued request. The released worker observes terminal state and creates nothing.
- **Publication first:** the worker pauses at its controlled checkpoint while holding the write transaction. A second thread attempts expiry. Once publication commits, expiry closes the ready artifact. It cannot become collectible again through redelivery.

The tests use events, not sleeps. Waiting at the same barrier while already holding the writer lock would produce a test-induced stall instead of this schedule. No guarantee of global exactly-once delivery follows: this is one at-most-one committed result in the local database, with explicit replay behavior.

### Delete independently of the release gate

`cleanup` is privileged maintenance with a trusted job ID and no keyring. It closes due jobs, removes their linked encrypted row and slot, releases capacity and commits a deletion receipt together. The selected storage is SQLite rows, so removal and receipt can share one local transaction.

A deletion-trigger or required deleted-event failure rolls that whole unit back. A separate transaction records `retry_required` where storage is usable. The copy remains unavailable, its reservation stays occupied, and an observed deadline breach is retained. If the database also cannot record the failure, the operation propagates failure; it must not fabricate a successful receipt.

An external object store would change this guarantee: object removal cannot be rolled back by SQLite. The receipt/reconciliation procedure from chapter 41 would then require a separate implementation and tests. This patch does not silently introduce that distributed storage boundary.

The removal deadline is fixed at access end plus 900 seconds. Completion after that deadline preserves `breached=1`; later success does not erase the breach. `deleted_at` is the first committed completion, and `retain_until` is seven days later. Cleanup replay does not reset either. For a terminal request that never made a payload, metadata retention starts at its effective terminal closure.

`purge` removes due job/events/retry metadata only after the reservation is clear. The job table uses `AUTOINCREMENT`, so a purged accepted job ID is not reused for a new request in this database history. Nonce reservations survive job deletion. A backup that rewinds database identity or nonce history still needs chapter 27/41's recovery design; AUTOINCREMENT does not solve rollback of the entire database.

def json_body(request):
    if request.content_type != "application/json" or len(request.body) > 4096:
        raise service.Problem(400,"invalid_request")
    def pairs(items):
        result = {}
        for key,value in items:
            if key in result: raise ValueError("duplicate key")
            result[key] = value
        return result
    def constant(value): raise ValueError("invalid JSON constant")
    try:
        return json.loads(request.body.decode("utf-8"),object_pairs_hook=pairs,parse_constant=constant)
    except (ValueError,UnicodeDecodeError,RecursionError) as exc:
        raise service.Problem(400,"invalid_request") from exc

        response["Allow"] = method
        return response

        if operation == "csrf": return JsonResponse({"token":get_token(request)})
