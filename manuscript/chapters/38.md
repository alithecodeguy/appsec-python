# 38. Normalize findings and prioritize work

Two reports point to the same debug assignment. A third row describes a high-severity dependency issue in an isolated tool. Which rows should become one issue, which evidence must remain separate, and who should act first?

This chapter turns two saved reports into a reviewable queue. We will merge a duplicate without losing either origin, keep suppression and reopening decisions visible, and prioritize three findings using exposure, uncertainty and ownership. Severity remains useful, but it cannot answer every operational question.

You need chapter 8's JSON, chapter 12's tests, chapter 29's distinction between a static claim and an actual path, and chapter 37's report protocol. Chapters 31–32 showed dependency/artifact identity. Chapters 33–36 showed why an accepted control or a successful check needs a subject, evidence and an owner.

By the end, you will be able to:

- Separate a tool result from the issue record used to coordinate work.
- Preserve report bytes, record pointers, native rule IDs and locations during normalization.
- Explain what a stable fingerprint includes and which similarities are insufficient for deduplication.
- Keep approved suppressions visible and invalidate them when scope or time changes.
- Distinguish CWE classes, CVE/advisory identities, CVSS severity and local priority.
- Publish a queue with a reason, an owner or routing owner, a next action and a deadline.

## 1. SARIF results, advisory identifiers and normalized finding records

### Normalize meaning without discarding the original

A **result** is a row produced by a tool. A **finding** in our queue is a coordinated issue tied to a project, asset and condition. Several results can support one finding. One report can also contain results about several different assets.

**Normalization** maps supported source formats into a common record. It should preserve the information needed to explain the mapping. Replacing a tool's original rule ID with a friendly label and deleting the input report would make later review much harder.

**Table T38-01. Information with different responsibilities**

| Information | Purpose | Where it remains |
| --- | --- | --- |
| Native tool/version/rule and result location | Explain what the producer reported | Origin record and saved report |
| Report filename, SHA-256 and JSON Pointer | Locate the exact saved result | Origin record |
| Source SHA-256, when supplied | Identify the source bytes the producer said it reviewed | Origin record; nullable when unavailable |
| Canonical project/asset/condition | Coordinate one issue across observations | Reviewed identity catalog and finding fingerprint |
| Severity, exposure, ownership and controls | Decide local response | Authored context snapshot with evidence reference |
| Suppression/closure history | Explain workflow state | Prior decision record and current state reason |

A **JSON Pointer** addresses a value inside a JSON document. `/observations/1` means the second observation. `/runs/0/results/0` means the first result of the first SARIF run. Pair the pointer with the report's hash: inserting a row can change an index even when its text stays the same.

The source file hash and report hash are different identities. A comment edit changes source bytes; a report reformat changes report bytes. Neither is automatically a new security condition. Keep both for evidence, and use a separately defined issue identity for coordination.

### The normalized record is a contract

Each current finding will contain a fingerprint, identity, context snapshot, lifecycle state/reason, priority/deadlines and an `origins` list. Each origin retains the normalized path **and** its native spelling, tool/version/rule, native level/classification, source/report hashes, pointer, column unit and selected native metadata.

The adapter does not copy arbitrary messages or source excerpts into the queue. The original result remains retrievable by hash and pointer. This limits unnecessary duplication of potentially private text. Store the raw reports and the queue under appropriate access controls; filenames, package names and decision records can themselves reveal information.

## 2. Stable fingerprints, deduplication, suppressed items and reopening

### Define what “the same issue” means

A **fingerprint** is a repeatable identifier for a chosen issue identity. Our input is a canonical JSON array:

```text
[project, asset_id, condition_id]
```

We hash that representation with SHA-256. Tool name, line, source/report hash, severity, component version and queue status are excluded. They describe observations or state that can change while the issue remains the same.

Excluding a line number is useful only if the semantic anchor is maintained correctly. Our `condition_id` is a **reviewed catalog value**, not an anchor magically inferred from any source. Each tool/rule/path/line selector has an explicit binding. When a line moves, a reviewer must update the selector while retaining the intended condition. An unmapped result fails publication instead of being silently dropped.

For the dependency, the condition includes the advisory namespace/ID, package and installation context. The asset is separate. Two installations of the same affected package must not collapse merely because they share an advisory. Similarly, the same basename `settings.py` in two directories does not establish identity.

Do not deduplicate solely on a CWE, message text, severity or native fingerprint from an unrelated producer. Cross-tool aliases need evidence that they refer to the same condition on the same asset. Store native fingerprints as producer metadata while applying your reviewed identity mapping.

| Input reference | Native rule | Reviewed issue key | Merge decision |
| --- | --- | --- | --- |
| `reports/local.json`, `/observations/1` | `CBK001` | `debug-public` | Preserve as first origin of the shared issue |

**Table T38-03. Selected lifecycle rules**

| Current observation and prior decision | Current state | Why |
| --- | --- | --- |
| First observation | `open` | There is no previous disposition |
| Positive observation on a new subject after closure | `reopened` | Earlier closure does not cover new positive evidence |
| Positive observation on the same subject marked closed | `needs_review` | Review the contradiction/replay; do not hide it or assume a new issue |
| Approval still current, same scope and current controls | `suppressed`, visible but not actionable | The reviewed exception still applies |
| Approval expired, scope changed or controls expired | `reopened` | The conditions for suppression no longer hold |
| Prior issue absent from the current results | Prior state retained in `unobserved_prior` | Absence alone does not prove a fix or adequate scan coverage |

This program does not automatically close issues. Closure requires a verified fix or justified disposition, tied to the right subject and a suitable retest. A fresh empty result set from a narrow checker is not a complete security proof. An input report that explicitly contains scan errors prevents publication of a newly approved queue.

The prior file is a reviewed input, not a state database automatically rewritten by this tool. A real issue system should preserve decision history and concurrent edits. The current example publishes a snapshot for review.

## 3. CWE weakness classes, CVE identifiers, CVSS severity and contextual impact

These labels answer different questions. Mixing them produces misleading records even when the JSON is valid.

**Table T38-04. Classification, identity, severity and response**

| Item | Question answered | What it does not establish |
| --- | --- | --- |
| CWE | What type of weakness is being described? | Which deployed instance is affected or how urgent this team should act |
| CVE or another advisory identifier | Which vulnerability/advisory record is being referenced? | A local installation, reachability or ownership |
| CVSS assessment | What severity is communicated by the specified vector and metric groups? | The complete operational response decision |
| Local priority | What should this organization do first, under its current facts and policy? | A replacement score that should be relabeled as CVSS |

MITRE's [CWE description](https://cwe.mitre.org/about/index.html) describes a weakness taxonomy. This fixture proposes [CWE-489, Active Debug Code](https://cwe.mitre.org/data/definitions/489.html), for the literal-debug candidate and [CWE-22, path restriction weakness](https://cwe.mitre.org/data/definitions/22.html), for the fictional advisory. These are authored candidate mappings, not proof that a deployed vulnerability has been demonstrated. The unresolved dynamic setting has no asserted weakness class.

The CVE Program's [official record repository](https://github.com/CVEProject/cvelistV5) provides published CVE records. A local rule such as `CBK001` is not a CVE. Our fictional advisory has an explicit `fictional` namespace and no invented CVE-shaped identity. A private application issue can still require urgent action without having a CVE.

### Keep a real score's provenance

FIRST's [CVSS v4.0 specification](https://www.first.org/cvss/v4.0/specification-document) defines Base, Threat, Environmental and Supplemental metric groups. Threat and Environmental choices can refine severity for the consumer's situation; Supplemental metrics add context without changing the score. Record the version, vector, metric-group scope and authority when using an actual score.

This exercise supplies no CVSS vector and calculates no CVSS score. Its `High` and `Medium` labels are authored queue inputs. A SARIF `warning` is preserved as a native level, not converted into a numeric vulnerability score. Do not average unrelated tool labels or call an ordinal queue position a CVSS value.

CVSS can incorporate valuable context. The remaining response still includes current exposure evidence, uncertainty, asset importance, an accountable owner, available containment and a deadline. An unassigned asset does not become less important because nobody has accepted its ticket.

### Preserve uncertainty about impact

The chapter 37 literal observation is syntactic. `EV38-01` **assumes for the exercise** that this module is selected for a public API handling private workspace notes. Its next action still includes verifying the effective runtime value and reducing exposure as needed. The record does not claim that a debug response was exploited.

`EV38-02` assumes the dynamic setting belongs to a public export path with private data and incomplete ownership. Its runtime value is unknown. The urgent action is to assign an owner and determine that value safely; a confirmed unsafe result would change remediation and containment decisions.

`EV38-03` assumes the maintenance operation is disabled, isolated from public request flow and restricted to synthetic maintenance inputs. Its control evidence is accepted only until the stated recheck time. These claims need real configuration/process/input evidence before use outside the exercise. “Offline” is not a synonym for harmless: an isolated parser can still receive an untrusted file through support or a batch transfer.

## 4. Reachability, asset importance, compensating controls and remediation deadlines

**Reachability** asks whether relevant input can reach the affected behavior in the deployed system. An open network port is only one part of that question. A background job can receive user-controlled data through a queue, and a command-line tool can process an externally supplied archive.

A **compensating control** reduces a particular exposure while the underlying condition remains. Give it evidence, an owner and a recheck condition. A disabled entry point and verified isolation can support a different schedule from an exposed public path. They do not erase the dependency issue or prove that every input channel is blocked.

Predict which of the two `High` findings should be handled first. Then decide whether the `Medium` unresolved export setting should wait behind the isolated dependency simply because of its label.

**Table T06. Severity, exposure and ownership in a remediation queue**

| Order | Finding and label | Exposure and importance | Owner and immediate reason | Next action |
| ---: | --- | --- | --- | --- |
| 1 | `debug-public`, High | Selected public configuration for private workspace notes | Web Platform; reduce a plausible exposed configuration risk and establish the runtime fact | Verify loaded `DEBUG`, restrict exposure as needed, correct the selected setting and retest |

The two `High` labels do not imply equal response order. The Medium item is second because a public path with private data and unknown effective configuration needs evidence now. This is the decision a severity-only descending sort would miss.

The missing owner remains `null` in the machine record. The routing owner is responsible for assignment, not silently presented as the team that can repair the export process. If assignment or evidence collection misses its deadline, escalate through the response/program owner. Do not let the issue sit indefinitely in a generic queue.

### Deadlines are authored policy decisions

The fixture policy is evaluated at `2026-11-26T12:00:00Z`, in ordinary UTC hours/days rather than business-day arithmetic:

**Table T38-05. Action deadlines and conditional remediation targets**

| Finding | Next-action deadline | Remediation target | Boundary |
| --- | --- | --- | --- |
| Public literal candidate | `2026-11-26T16:00:00Z` | `2026-11-27T12:00:00Z` | Validate effective setting and mitigate promptly; retest before closure |
| Dynamic public setting | `2026-11-26T16:00:00Z` | Not yet assigned | First determine the value and repair owner; confirmed exposure requires a new remediation decision |
| Isolated dependency | `2026-11-27T12:00:00Z` | `2026-12-03T12:00:00Z` | Recheck controls by their expiry and plan the update before enabling the operation |

These dates are fictional exercise policy, not a universal standard or a scheduled task. The dependency's longer planning target does not extend its one-day control validity or expired suppression. If controls cannot be reconfirmed, the program raises it to priority 2 for reassessment. The next-action deadline is capped at the control recheck time, even if that is earlier than twenty-four hours.

The code refuses unrecognized context values. It also refuses to give the lower priority to an isolated asset whose relevant operation's reachability is unknown. A typo or missing evidence must not become an automatic risk discount.

### The executable merge and publication

The following complete program handles the supplied report formats, curated bindings, lifecycle and authored policy. It writes the full `queue.json` only after all supported inputs have been processed successfully. Source-location URIs are treated as labels; they are not fetched or opened as evidence files.

Filename: `examples/ch38/queue_review.py`.

```python
"""Normalize selected local fixture reports and publish a review queue."""
import argparse
from datetime import datetime, timedelta, timezone
import hashlib
import json
import os
from pathlib import Path, PurePosixPath
import re
import sys
import tempfile
from urllib.parse import urlsplit


def utc(value):
    instant = datetime.fromisoformat(value)
    if instant.tzinfo is None or instant.utcoffset() is None:
        raise ValueError("timestamp_requires_offset")
    return instant.astimezone(timezone.utc)


def stamp(value):
    return value.isoformat(timespec="seconds").replace("+00:00", "Z")


def canonical(value):
    return json.dumps(value, sort_keys=True, separators=(",", ":"), ensure_ascii=True)


def fingerprint(identity):
    return hashlib.sha256(canonical(identity).encode()).hexdigest()


def relative_path(value):
    uri = urlsplit(value)
    path = PurePosixPath(value)
    if (uri.scheme or uri.netloc or uri.query or uri.fragment or path.is_absolute()
            or ".." in path.parts or "\\" in value or "%" in value or str(path) == "."):
        raise ValueError("unsupported_relative_path")
    return path.as_posix()


def load(path):
    with Path(path).open("rb") as source:
        raw = source.read(1024 * 1024 + 1)
    if len(raw) > 1024 * 1024:
        raise ValueError("report_too_large")
    return json.loads(raw), hashlib.sha256(raw).hexdigest()


def observations(document, format_name):
    if format_name == "casebook37":
        if (document["schema_version"] != 1 or document["tool"] != "casebook-config-check"
                or document["errors"] or document["exit_code"] not in (0, 1, 3)):
            raise ValueError("incomplete_or_unknown_local_report")
        known = {(relative_path(item["path"]), item["source_sha256"]) for item in document["files"]}
        for index, row in enumerate(document["observations"]):
            if (relative_path(row["path"]), row["source_sha256"]) not in known:
                raise ValueError("source_identity_mismatch")
            yield {"tool": document["tool"], "tool_version": document["tool_version"],
                   "rule": row["rule_id"], "path": row["path"], "line": row["line"],
                   "column": row["column"], "source_sha256": row["source_sha256"],
                   "pointer": f"/observations/{index}", "native_level": None,
                   "classification": row["classification"], "native_suppressions": [],
                   "native_fingerprints": {}}
    elif format_name == "sarif":
        if document["version"] != "2.1.0":
            raise ValueError("unsupported_sarif_version")
        for run_index, run in enumerate(document["runs"]):
            if run["columnKind"] != "unicodeCodePoints":
                raise ValueError("unsupported_column_unit")
            if any(item.get("executionSuccessful") is False for item in run.get("invocations", [])):
                raise ValueError("failed_sarif_invocation")
            driver = run["tool"]["driver"]
            for index, result in enumerate(run["results"]):
                location, = result["locations"]
                physical = location["physicalLocation"]
                artifact = physical["artifactLocation"]
                if "uriBaseId" in artifact:
                    raise ValueError("unsupported_uri_base")
                region = physical["region"]
                yield {"tool": driver["name"], "tool_version": driver["version"],
                       "rule": result["ruleId"], "path": artifact["uri"],
                       "line": region["startLine"], "column": region["startColumn"],
                       "source_sha256": result.get("properties", {}).get("source_sha256"),
                       "pointer": f"/runs/{run_index}/results/{index}",
                       "native_level": result.get("level"), "classification": None,
                       "native_suppressions": [{key: item[key] for key in ("kind", "status") if key in item}
                                               for item in result.get("suppressions", [])],
                       "native_fingerprints": result.get("partialFingerprints", {})}
    else:
        raise ValueError("unsupported_report_format")


def collect(root, catalog):
    rows = []
    for entry in catalog["inputs"]:
        if entry["subject_id"] != catalog["subject_id"]:
            raise ValueError("report_subject_mismatch")
        name = relative_path(entry["path"])
        document, digest = load(Path(root) / name)
        for row in observations(document, entry["format"]):
            row["native_path"] = row["path"]
            row["column_kind"] = "unicodeCodePoints"
            row["path"] = relative_path(row["path"])
            if any(type(row[key]) is not int or row[key] < 1 for key in ("line", "column")):
                raise ValueError("invalid_location")
            if row["source_sha256"] is not None and re.fullmatch(r"[0-9a-f]{64}", row["source_sha256"]) is None:
                raise ValueError("invalid_source_digest")
            rows.append({**row, "report": name, "report_sha256": digest})
    return rows


def scope(context):
    return {key: context[key] for key in ("asset_id", "component_version", "exposure", "evidence_ref")}


def lifecycle(context, previous, subject, now):
    if previous is None:
        return "open", "first_observation"
    if previous["state"] == "closed":
        return (("reopened", "positive_on_new_subject") if previous["verified_subject"] != subject
                else ("needs_review", "positive_on_closed_subject"))
    if previous["state"] == "suppressed":
        approval = previous["suppression"]
        if (approval["approved_by"] and approval["reason"] and approval["evidence_ref"]
                and utc(approval["expires_at"]) > now and approval["scope"] == scope(context)
                and (context["controls_valid_until"] is None
                     or utc(context["controls_valid_until"]) > now)):
            return "suppressed", "current_scoped_approval"
        return "reopened", "suppression_expired_or_scope_changed"
    if previous["state"] not in ("open", "reopened", "needs_review"):
        raise ValueError("unsupported_previous_state")
    return previous["state"], "still_observed"


def priority(context, now):
    if (context["exposure"] not in ("public", "isolated")
            or context["reachability"] not in ("selected_configuration", "unknown", "disabled_operation")):
        raise ValueError("unsupported_context_value")
    if context["exposure"] == "public" and context["reachability"] == "selected_configuration":
        rank, hours, fix_days = 1, 4, 1
        reason = "Public selected configuration protects private workspace data; verify and reduce exposure now."
    elif (context["exposure"] == "public" or context["reachability"] != "disabled_operation"
          or not context["controls_valid_until"]
          or utc(context["controls_valid_until"]) <= now):
        rank, hours, fix_days = 2, 4, None
        reason = "Resolve public-path or control uncertainty promptly; missing ownership does not reduce priority."
    else:
        rank, hours, fix_days = 3, 24, 7
        reason = "Disabled isolated maintenance path has time-bounded controls; plan the update before enabling it."
    action_due = now + timedelta(hours=hours)
    if rank == 3:
        action_due = min(action_due, utc(context["controls_valid_until"]))
    return {"priority": rank, "reason": reason,
            "next_action_due_at": stamp(action_due),
            "remediation_target_at": stamp(now + timedelta(days=fix_days)) if fix_days else None}


def merge(rows, catalog, prior):
    if catalog["schema_version"] != 1 or catalog["synthetic"] is not True or prior["schema_version"] != 1:
        raise ValueError("unsupported_training_catalog")
    now = utc(catalog["as_of"])
    bindings = {}
    for item in catalog["bindings"]:
        selector = (item["tool"], item["rule"], relative_path(item["path"]), item["line"])
        if selector in bindings:
            raise ValueError("ambiguous_binding")
        bindings[selector] = item["key"]
    previous = {fingerprint(item["identity"]): item for item in prior["records"]}
    if len(previous) != len(prior["records"]):
        raise ValueError("duplicate_previous_identity")
    grouped = {}
    for row in rows:
        key = bindings[(row["tool"], row["rule"], row["path"], row["line"])]
        context = catalog["contexts"][key]
        identity = [catalog["project"], context["asset_id"], context["condition_id"]]
        identifier = fingerprint(identity)
        if identifier not in grouped:
            state, reason = lifecycle(context, previous.get(identifier), catalog["subject_id"], now)
            grouped[identifier] = {"key": key, "fingerprint": identifier, "identity": identity,
                                   "context": context, "state": state, "state_reason": reason,
                                   "actionable": state != "suppressed", "origins": [], **priority(context, now)}
        elif grouped[identifier]["context"] != context:
            raise ValueError("identity_context_conflict")
        for origin in grouped[identifier]["origins"]:
            if (origin["path"] == row["path"] and origin["source_sha256"] and row["source_sha256"]
                    and origin["source_sha256"] != row["source_sha256"]):
                raise ValueError("conflicting_source_identity")
        if row not in grouped[identifier]["origins"]:
            grouped[identifier]["origins"].append(row)
    findings = list(grouped.values())
    for finding in findings:
        finding["origins"].sort(key=canonical)
    findings.sort(key=lambda item: (not item["actionable"], item["priority"], item["fingerprint"]))
    unobserved = [{**item, "observed_this_run": False, "reason": "not_seen_not_auto_closed"}
                  for identifier, item in sorted(previous.items()) if identifier not in grouped]
    return {"schema_version": 1, "synthetic": True, "as_of": stamp(now),
            "subject_id": catalog["subject_id"], "raw_observations": len(rows),
            "distinct_findings": len(findings), "findings": findings, "unobserved_prior": unobserved}


def publish(destination, document, protected):
    destination = Path(destination)
    if destination.resolve() in {Path(path).resolve() for path in protected}:
        raise ValueError("output_would_replace_input")
    temporary = None
    try:
        with tempfile.NamedTemporaryFile(mode="w", encoding="utf-8", dir=destination.parent,
                                         prefix=".queue-", delete=False) as output:
            temporary = Path(output.name)
            output.write(json.dumps(document, sort_keys=True, ensure_ascii=True, indent=2) + "\n")
        os.replace(temporary, destination)
    finally:
        if temporary is not None:
            temporary.unlink(missing_ok=True)


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("catalog", type=Path)
    parser.add_argument("prior", type=Path)
    parser.add_argument("output", type=Path)
    args = parser.parse_args()
    try:
        catalog, catalog_digest = load(args.catalog)
        prior, prior_digest = load(args.prior)
        rows = collect(args.catalog.parent, catalog)
        queue = merge(rows, catalog, prior)
        queue["decision_inputs"] = [
            {"path": args.catalog.as_posix(), "sha256": catalog_digest},
            {"path": args.prior.as_posix(), "sha256": prior_digest},
        ]
        protected = [args.catalog, args.prior] + [args.catalog.parent / item["path"] for item in catalog["inputs"]]
        publish(args.output, queue, protected)
    except (OSError, ValueError, KeyError, TypeError):
        print("queue_input_or_publish_failed", file=sys.stderr)
        return 2
    print(f"merged {len(rows)} observations into {queue['distinct_findings']} findings")
    for finding in queue["findings"]:
        context = finding["context"]
        owner = context["owner"] or f"UNASSIGNED; route to {context['routing_owner']}"
        print(f"P{finding['priority']} {finding['key']}: {context['severity']}; "
              f"{finding['state']}; owner={owner}; origins={len(finding['origins'])}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

The input loader limits each JSON file to one MiB. This is a bounded local exercise, not a hardened service for hostile uploads. The adapter does not perform complete SARIF JSON Schema validation or implement all SARIF location and result forms. It rejects unsupported shapes, column units and path forms instead of producing an apparently complete queue from a guessed interpretation.

The `collect` step preserves source/report provenance. The `merge` step uses reviewed bindings and creates one issue per fingerprint. `lifecycle` applies only the trusted prior decision file. `priority` applies the stated context policy; it is not a risk-scoring standard. `publish` uses a temporary file and replacement in the destination directory so readers do not see a partially written JSON document.

The output cannot replace the catalog, prior file or reports. An input/publish error returns `2` with a controlled stderr message and leaves an existing queue unchanged. That previous file is a **last known snapshot**, not a newly approved current queue. A runner must retain the failure signal and not refresh its apparent collection time. The example does not claim power-loss durability or a concurrent multi-writer issue database.

### Test the decisions and the failure state

The tests challenge deduplication, preservation, priority and lifecycle. They also run the CLI with a deliberately incomplete source report and compare the stored output bytes before and after failure.

Filename: `examples/ch38/test_queue_review.py`.

```python
import copy
import json
from pathlib import Path
import shutil
import subprocess
import sys
import tempfile
import unittest

from queue_review import collect, fingerprint, load, merge, publish, relative_path


ROOT = Path(__file__).resolve().parent


class QueueTests(unittest.TestCase):
    def setUp(self):
        self.catalog, _ = load(ROOT / "catalog.json")
        self.prior, _ = load(ROOT / "prior.json")
        self.rows = collect(ROOT, self.catalog)

    def queue(self):
        return merge(self.rows, self.catalog, self.prior)

    def test_four_rows_merge_to_three_and_keep_both_origins(self):
        result = self.queue()
        self.assertEqual((result["raw_observations"], result["distinct_findings"]), (4, 3))
        finding = result["findings"][0]
        self.assertEqual(finding["key"], "debug-public")
        self.assertEqual({(o["report"], o["pointer"]) for o in finding["origins"]}, {
            ("reports/local.json", "/observations/1"),
            ("reports/second.sarif", "/runs/0/results/0")})
        for origin in finding["origins"]:
            _, digest = load(ROOT / origin["report"])
            self.assertEqual(origin["report_sha256"], digest)

    def test_equal_high_labels_have_different_priority_and_medium_is_second(self):
        findings = self.queue()["findings"]
        self.assertEqual([r["key"] for r in findings], ["debug-public", "debug-dynamic", "archive-offline"])
        self.assertEqual([r["context"]["severity"] for r in findings], ["High", "Medium", "High"])
        self.assertIsNone(findings[1]["context"]["owner"])
        self.assertEqual(findings[1]["context"]["routing_owner"], "AppSec Intake")

    def test_producer_suppression_is_preserved_without_becoming_global_approval(self):
        finding = self.queue()["findings"][0]
        self.assertEqual(finding["state"], "reopened")
        source = next(o for o in finding["origins"] if o["native_suppressions"])
        self.assertEqual(source["native_suppressions"][0]["status"], "accepted")
        self.assertTrue(finding["actionable"])

    def test_fresh_positive_and_expired_approval_reopen(self):
        findings = self.queue()["findings"]
        self.assertEqual(findings[0]["state_reason"], "positive_on_new_subject")
        self.assertEqual(findings[2]["state_reason"], "suppression_expired_or_scope_changed")

    def test_valid_approval_stays_visible_and_scope_change_reopens(self):
        approval = self.prior["records"][1]["suppression"]
        approval["expires_at"] = "2026-11-27T11:00:00Z"
        finding = next(f for f in self.queue()["findings"] if f["key"] == "archive-offline")
        self.assertEqual((finding["state"], finding["actionable"]), ("suppressed", False))
        original = finding["fingerprint"]
        self.catalog["contexts"]["archive-offline"]["component_version"] = "1.4.1"
        finding = next(f for f in self.queue()["findings"] if f["key"] == "archive-offline")
        self.assertEqual(finding["state"], "reopened")
        self.assertEqual(finding["fingerprint"], original)

    def test_expired_control_cannot_keep_suppression_or_low_priority(self):
        self.prior["records"][1]["suppression"]["expires_at"] = "2026-11-28T00:00:00Z"
        self.catalog["contexts"]["archive-offline"]["controls_valid_until"] = "2026-11-26T11:59:59Z"
        finding = next(f for f in self.queue()["findings"] if f["key"] == "archive-offline")
        self.assertEqual((finding["state"], finding["priority"]), ("reopened", 2))

    def test_fingerprint_is_scoped_and_ignores_line_severity_and_source_version(self):
        original = self.queue()["findings"][0]["fingerprint"]
        for row in self.rows:
            if row["path"] == "fixtures/literal_debug.py":
                row["line"] = 8
                row["source_sha256"] = "1" * 64
        for binding in self.catalog["bindings"]:
            if binding["path"] == "fixtures/literal_debug.py":
                binding["line"] = 8
        self.catalog["contexts"]["debug-public"]["severity"] = "Medium"
        self.catalog["subject_id"] = "newer-fixture-subject"
        changed = next(f for f in self.queue()["findings"] if f["key"] == "debug-public")
        self.assertEqual(changed["fingerprint"], original)
        identity = changed["identity"]
        self.assertNotEqual(fingerprint([identity[0], "different-asset", identity[2]]), original)

    def test_reordering_and_replayed_input_do_not_duplicate_origins(self):
        baseline = self.queue()
        self.assertEqual(merge(list(reversed(self.rows)), self.catalog, self.prior), baseline)
        repeated = merge(self.rows + self.rows, self.catalog, self.prior)
        self.assertEqual(repeated["findings"], baseline["findings"])

    def test_absence_does_not_close_previous_findings(self):
        result = merge([], self.catalog, self.prior)
        self.assertEqual(len(result["unobserved_prior"]), 2)
        self.assertEqual({r["state"] for r in result["unobserved_prior"]}, {"closed", "suppressed"})
        self.assertTrue(all(r["reason"] == "not_seen_not_auto_closed" for r in result["unobserved_prior"]))

    def test_positive_on_same_closed_subject_requires_review(self):
        self.prior["records"][0]["verified_subject"] = self.catalog["subject_id"]
        self.assertEqual(self.queue()["findings"][0]["state"], "needs_review")

    def test_unmapped_binding_and_conflicting_source_identity_are_refused(self):
        rows = copy.deepcopy(self.rows)
        rows[0]["rule"] = "NEW_RULE"
        with self.assertRaises(KeyError):
            merge(rows, self.catalog, self.prior)
        rows = copy.deepcopy(self.rows)
        source = next(r for r in rows if r["tool"] == "casebook-sarif-training" and r["rule"] == "DBG_LITERAL")
        source["source_sha256"] = "0" * 64
        with self.assertRaisesRegex(ValueError, "conflicting_source_identity"):
            merge(rows, self.catalog, self.prior)

    def test_path_variants_are_not_collapsed_by_basename(self):
        self.assertEqual(relative_path("./fixtures/literal_debug.py"), "fixtures/literal_debug.py")
        self.assertNotEqual(relative_path("one/settings.py"), relative_path("two/settings.py"))
        for path in ("../settings.py", "file:///settings.py", "x%2Fy.py", "C:\\settings.py"):
            with self.assertRaises(ValueError):
                relative_path(path)

    def test_subject_mismatch_and_bad_column_units_are_refused(self):
        self.catalog["inputs"][0]["subject_id"] = "wrong-subject"
        with self.assertRaisesRegex(ValueError, "report_subject_mismatch"):
            collect(ROOT, self.catalog)
        from queue_review import observations
        report, _ = load(ROOT / "reports/second.sarif")
        report["runs"][0]["columnKind"] = "utf16CodeUnits"
        with self.assertRaisesRegex(ValueError, "unsupported_column_unit"):
            list(observations(report, "sarif"))

    def test_unknown_context_cannot_silently_receive_low_priority(self):
        context = self.catalog["contexts"]["archive-offline"]
        context["exposure"] = "public-typo"
        with self.assertRaisesRegex(ValueError, "unsupported_context_value"):
            self.queue()
        context["exposure"] = "isolated"
        context["reachability"] = "unknown"
        finding = next(f for f in self.queue()["findings"] if f["key"] == "archive-offline")
        self.assertEqual(finding["priority"], 2)

    def test_action_deadline_does_not_outlive_control_recheck(self):
        self.catalog["contexts"]["archive-offline"]["controls_valid_until"] = "2026-11-26T12:30:00Z"
        finding = next(f for f in self.queue()["findings"] if f["key"] == "archive-offline")
        self.assertEqual(finding["next_action_due_at"], "2026-11-26T12:30:00Z")

    def test_publish_refuses_inputs_and_failure_keeps_last_queue(self):
        with tempfile.TemporaryDirectory() as directory:
            target = Path(directory) / "queue.json"
            publish(target, {"last_good": True}, [])
            before = target.read_bytes()
            with self.assertRaises(ValueError):
                publish(target, {}, [target])
            self.assertEqual(target.read_bytes(), before)
            copy = Path(directory) / "exercise"
            shutil.copytree(ROOT / "reports", copy / "reports")
            for name in ("catalog.json", "prior.json"):
                shutil.copyfile(ROOT / name, copy / name)
            report, _ = load(copy / "reports/local.json")
            report["errors"] = [{"code": "syntax_error"}]
            (copy / "reports/local.json").write_text(json.dumps(report))
            result = subprocess.run([sys.executable, str(ROOT / "queue_review.py"),
                                     str(copy / "catalog.json"), str(copy / "prior.json"), str(target)],
                                    text=True, capture_output=True)
            self.assertEqual(result.returncode, 2)
            self.assertEqual(result.stderr.strip(), "queue_input_or_publish_failed")
            self.assertEqual(target.read_bytes(), before)
            self.assertFalse(list(Path(directory).glob(".queue-*")))


if __name__ == "__main__":
    unittest.main()
```

### Independent practice answers

**1. Another worker.** Keep the project and verified advisory/package condition relationship, but use the other worker's asset/installation context. Its fingerprint must differ. Preserve each result's report hash, pointer, native rule and location; do not merge merely because the advisory string matches. **2. Moved finding.** Review the relocation and update the binding to the new location while retaining the same semantic condition/asset identity. **3. Expired local approval.** Reopen or otherwise route the current condition for review; retain the producer's suppression in the origins.
